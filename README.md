# Мой сайт

Простой обычный статический сайт на HTML/CSS/JS, размещённый на GitHub Pages по адресу `https://niceyuki.github.io`.

## Быстрый старт

Открой `index.html` в браузере или запусти локальный сервер:

```bash
python -m http.server 8000
```

и перейди на `http://localhost:8000`.

## Как задеплоить на GitHub Pages

1. Создай репозиторий `username.github.io` (замени `username` на свой логин).
2. Заливай файлы в репозиторий через `git push`.
3. GitHub автоматически опубликует сайт по адресу `https://username.github.io`.

## Файлы

- `index.html` — разметка страницы
- `style.css` — стили
- `script.js` — скрипты
